¿Qué es una Skill en AgentHub?

Una Skill es una unidad funcional autónoma que equipa a un Agente IA con herramientas para interactuar con el entorno real: ejecutar navegación web en sandbox seguro, procesar y consultar documentos corporativos con OCR y RAG, negociar y agendar calendarios vía OAuth o disparar flujos de trabajo en CRMs/ERPs empresariales.
